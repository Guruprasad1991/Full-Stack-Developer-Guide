# Full Stack Developer Guide

This repository is a personal practice project created for learning and exploring the journey from frontend development to full stack development.

It is inspired by the Scrimba free 48-hour workshop and is meant to help developers build practical skills through small, focused projects and hands-on exercises.

## Purpose

This repo is designed for:

- frontend developers who want to transition into full stack development
- learners who want to practice real-world web development concepts
- developers exploring APIs, Node.js, backend logic, and data flow
- anyone building a strong foundation through smaller projects

## What this repository includes

The projects in this repo cover a variety of topics including:

- HTML and CSS fundamentals
- Flexbox and layout design
- Responsive UI styling
- JavaScript basics and DOM manipulation
- API handling and fetch usage
- Node.js fundamentals
- Working with local data and backend routing
- Creating simple server-side logic
- Building small practical web apps

## Learning path

The repo follows a gradual progression from frontend to full stack:

1. HTML/CSS basics
2. Styling and layout practice
3. JavaScript and UI interaction
4. API learning and data fetching
5. Node.js server setup
6. Building backend logic and routes
7. Connecting frontend concepts with backend services

## Repository structure

- `business-card/` — simple profile card UI
- `First Line of CSS/` — CSS basics practice
- `Flexbox/` — flexbox layout examples
- `Google Search page/` — static mock Google homepage
- `How to Handle API/` — API handling examples
- `Node js/` — backend and Node.js practice projects
- `Personal website/` — personal portfolio-style page
- `Space Exploration/` — landing page design exercise
- `index.html` — root project entry page

## Tools and technologies used

- HTML
- CSS
- JavaScript
- Node.js
- HTTP server basics
- REST API concepts

## Recommended learning flow

- Start with the frontend UI projects
- Move into the JavaScript and API examples
- Study the Node.js exercises and backend structure
- Try connecting the front-end and back-end ideas together
- Build your own small full stack app based on the concepts learned here

## Note

This repository is a personal learning repo and is not meant to be a production-ready application. It is focused on practice, experimentation, and understanding how frontend and backend development connect.
